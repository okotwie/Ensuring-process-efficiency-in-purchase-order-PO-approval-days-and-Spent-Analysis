# Ensuring-process-efficiency-in-purchase-order-PO-approval-days-and-Spent-Analysis
Analysis reviewed 203 suppliers with material groups which include asset, etc with a yearly spent analysis show orders in material groups and buyer’s spent. Recommend where firms see the need to adapt strategies to minimise cost in specific category by ensuring timely approval of purchase orders, by creating an l dashboard to monitor key indexes. 
Problem Statement
The objective of this project is to analyze spent data to understand where firm needs to focus to ensure cost-efficiency optimization and process performance in terms of timely PO approval to ensure goods & services are delivered on time to prevent production disruption. Hence the analysis seeks to answer the following business challenges/questions;
1.	Which category or material group is the highest spent within a financial year?
2.	Which approver’s have the highest PO approval aged days to ensure the need to streamline?

Data Understanding
Dataset Description;
	Number of records: 203 
	Number of columns: 21
Key Fields: PO numbers, PO value (Price X PO quantity), PO approval days, Material Group, PO creator, PO approver
Methodology 
1.	Data cleaning; Check 64 duplicates, removed 1212 unique values and empty cells, spaces and etc
2.	Slight feature engineering: Inserted a new column-PO approval ageing.
3.	Exploratory Analysis: Pivot tables to summarize spent per category or material group, and PO aged days per PO approvers 
4.	Analysis Techniques: formula segmentation thus M2 (PO approved date)-K2 (PO created date) 

Visualization: A dashboard with bar charts a donut chat and KPI cards as shown below.

Recommendations
1.	Ensure strategic sourcing to identify substitute suppliers with competitive rates to supply IT equipment or better use as a benchmark for discount from existing supplier.
